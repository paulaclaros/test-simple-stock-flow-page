Saber qué hay para vender, y qué se ha vendido.

Un sistema de inventario y ventas que responde las dos preguntas sin contar a mano: el stock que muestra el catálogo es el stock que hay, y el reporte de un período cerrado dice hoy lo mismo que dirá dentro de un año.

Principio Central

Invariantes Innegociables

  • Stock Real: Descuento atómico de existencias con prevención de condiciones de carrera (409 Conflict).
  • Inmutabilidad: Una venta registrada no se altera ni se borra.
  • Baja Lógica: Los productos vendidos se dan de baja, preservando el histórico.
  • Cálculo en Demanda: Ni total ni subtotal se almacenan en base de datos.

Qué hace el sistema

Cuatro módulos esenciales con reglas de negocio estrictas:

📦

Catálogo Comercial

Búsqueda por texto insensible a mayúsculas y filtro por categorías. Productos con nombre, precio, existencias e imagen. Los productos dados de baja desaparecen del catálogo activo.

🛒

Punto de Venta (POS)

Carrito multi-línea con validación inmediata de existencias. Descuento atómico y concurrente: dos cajas no pueden vender simultáneamente la última unidad.

📄

Historial de Ventas

Consulta de transacciones por rango de fechas. Cada línea congela el precio unitario y el nombre del producto al momento exacto de la venta.

📊

Reportes de Ventas

Agregación resuelta 100% en el motor PostgreSQL. Agrupado por producto y categoría congelada, calculando unidades vendidas y recaudación total.

Cómo está hecho

Desarrollo guiado por especificación (SDD) sobre Arquitectura Hexagonal

Backend

PHP con Laravel (Arquitectura Hexagonal)

  • Dominio Puro: Entidades (Product, Sale), Value Objects (Money, Quantity, DateRange) sin dependencias externas.
  • Casos de Uso: Orquestación desacoplada (1 acción = 1 clase).
  • PostgreSQL 16: Esquema propio sales, tablas en singular (product, sale, etc.).
  • Seguridad: Tokens JWT con expiración y control de roles (admin y seller).
Frontend

React + Vite

  • Interfaz SPA rápida y reactiva con TypeScript.
  • Punto de venta interactivo con carrito y verificación de existencias.
  • Filtros dinámicos y reportes con intervalos de fechas.
  • Nginx como Reverse Proxy hacia la API (sin problemas de CORS).

Cómo levantarlo en tu máquina

Requisito único: tener instalado Docker

# 1. Entrar al repositorio de infraestructura
cd test-simple-stock-flow-infra

# 2. Configurar variables de entorno
cp .env.example .env

# 3. Levantar la pila completa
docker compose up -d --wait

El portal web quedará disponible en http://localhost:8080.
Credenciales del administrador inicial: admin / Admin123*
